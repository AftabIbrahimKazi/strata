Variants

One variant per class token — hover:bg-primary, not hover:[bg-primary text-white]. The grouped form cannot work: the HTML parser splits class on whitespace before any CSS is consulted, so hover:[a p-3 b] becomes the three tokens hover:[a, p-3, b] — the middle one a bare p-3 that would apply permanently.

Breakpoints need no new syntax. Strata already spells them inside the utility, so a variant is just a prefix: hover:w-md-[40%].

1 · Interaction states

hover:bg-primary
hover:text-white
active:bg-dark
(hold click)

hover: is emitted inside @media (hover: hover), so it never sticks on a touch device.

2 · Form states

Styled with user-invalid: — nothing happens until you have actually interacted. Both variants ship; invalid: fires on page load for empty required fields, which is why forms styled with it look angry before anyone types.

3 · Structural

  • first: is bold
  • even row
  • odd:bg-light
  • even row
  • last: is primary

Every item carries the identical class string — the variants select which one each rule applies to.

4 · Relational — group-* and peer-*

group-hover: — hover the card, the child reacts

group-hover:text-primary …and this fades in

The trigger carries group; the styled elements carry the variant.

peer-checked: — a sibling after the trigger

peer-checked:text-success

Uses the general sibling combinator, so the target must come after its peer in source order.

5 · Environment — these wrap in @media

motion-reduce:bg-warning
motion-safe:bg-success
portrait: / landscape:
print:d-none
(gone in print preview)

One of the first two is always active — they are complementary halves of prefers-reduced-motion. Rotate a phone, or resize to a portrait window, to flip the third.

6 · Pseudo-elements

marker:text-primary on the <ul>

  • the marker is styled
  • from a class on the parent

marker and selection emit two rules — the element and its descendants — because you put the class on the list and mean the items.

selection:bg-primary — drag to select

Select this sentence and the highlight uses the brand colour.

before: / after:

before/after get content: "" automatically — without it they render nothing at all.

7 · Composition

hover:w-md-[40%]

Variant + breakpoint + arbitrary value. Routes to the st-utilities-md sub-layer, exactly as the bare utility does.

hover:focus:bg-primary

Variants stack. This one needs hover and focus at once — click it, then hover.

motion-safe:hover:shadow-lg

A media variant wrapping a pseudo-class variant — no special case for the pair.

8 · Direction

dir="rtl" on the ancestor
ltr:text-start

Two selectors are emitted for each — dir is usually on an ancestor but may sit on the element itself.
