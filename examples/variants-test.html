Variants

Pseudo-classes, pseudo-elements and relational states, written as a prefix on any utility. Each row below shows the class you write, the live element, and what you should do to see it fire.

One variant per class token. hover:[bg-primary text-white] cannot work on any host: the HTML parser splits class on whitespace into a token list before CSS is consulted, so it becomes hover:[bg-primary + text-white] — the first token is malformed and any middle token would apply permanently.

A trap this page fell into, worth knowing before you use variants.

Custom CSS is unlayered, and unlayered rules beat every Strata layer regardless of specificity. An earlier version of this file styled its demo tiles with background: var(--st-bg) — which silently defeated hover:bg-primary, odd:bg-light and every other background variant on the page. The demos rendered; they just did nothing.

The same applies in your own project: to override a state, you must name the state. .card { background: white } will not suppress a hover: background — write .card:hover { … } instead.

1 · Interaction

The everyday states. hover: is emitted inside @media (hover: hover), so it can never stick on a touch device.

hover:bg-primaryhover:text-white
Hover me
Fills with brand colour while the pointer is over it.
focus-visible:outline-primary
Press Tab until it is focused. A ring appears for keyboard focus but not for a mouse click.
active:bg-darkactive:text-white
Press and hold
Darkens only while the mouse button is held down.
focus-within:shadow-lg
The container gains a shadow when anything inside it is focused.

2 · Form state

Seventeen form variants ship. The pair worth understanding is invalid: and user-invalid:.

invalid: fires on page load for any empty required field — so a form styled with it looks angry before the visitor has typed anything.

user-invalid: waits for interaction. Both ship, because both are occasionally what you want. Use user-invalid: for validation feedback.

invalid:border-danger
Already red, untouched. This is the behaviour you usually do not want.
user-invalid:border-danger
Neutral until you type something invalid and leave the field. Compare with the row above.
checked:bg-success
Toggle either box.
disabled:opacity-50disabled:cursor-not-allowed
Static — the state is set by the disabled attribute.
placeholder:fst-italica pseudo-element
Styles ::placeholder. Type in the field and the italic text is replaced.

3 · Structural

Position within a parent. Every item below carries the identical class string — the variants decide which rule applies to which.

first:fw-bold odd:bg-primary odd:text-white last:text-primary
  • Item one
  • Item two
  • Item three
  • Item four
Static. Item one is bold, items one and three are filled, item four is brand-coloured — all from one shared class string.

Note the pairing: odd:bg-primary alone would leave the text at its inherited colour, so odd:text-white goes with it. A background utility never sets a text colour for you.

4 · Relational — group and peer

Style one element from the state of another. The trigger carries group or peer; the element being styled carries the variant.

group-hover:text-primary group-hover:opacity-100
Parent card Hidden until the card is hovered
Hover anywhere on the card — both children react. Uses a descendant combinator.
peer-checked:text-success peer-checked:fw-bold
This sibling responds
Uses the general sibling combinator, so the styled element must appear after its peer and share its parent. Wrapping the input in a <label> around both would break it.

6 · Environment

These wrap the rule in @media rather than matching a selector, so they respond to the device and to OS accessibility settings — not to anything you can click.

motion-safe:bg-successmotion-reduce:bg-warning
One of these is always active
Green normally; amber if "reduce motion" is on in your OS settings. Toggle it and reload.
portrait:bg-infolandscape:bg-primary
Follows window orientation
Resize the window taller than it is wide to flip it.
print:d-none
Hidden when printed
Open print preview (Ctrl+P) — this tile is gone.
forced-colors:fw-bold
Bold in forced-colors mode
Only visible with Windows High Contrast enabled.

7 · Direction

Two selectors are emitted for each, because dir is usually on an ancestor but may sit on the element itself.

rtl:text-end
dir="rtl" on the parent
Static. Aligns to the right inside an RTL ancestor.
ltr:text-start
dir="ltr" inherited from <html>
Static. The complementary case.

8 · Composition

Variants stack, and they compose with breakpoints and arbitrary values without any additional syntax — the breakpoint stays inside the utility, exactly where Strata already puts it.

hover:w-md-[60%]
Variant + breakpoint + arbitrary value
Above 768px, hovering shrinks it to 60%. Below that, hovering does nothing. Routes to the st-utilities-md sub-layer like the bare utility.
hover:focus:bg-primary
Needs both states at once
Click it to focus, then move the pointer away and back. Only fills when hovered and focused.
motion-safe:hover:shadow-lg
Media variant wrapping a state variant
Hover raises it — unless "reduce motion" is on.
