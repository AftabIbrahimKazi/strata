Responsive arbitrary values

Every bar below is sized by an arbitrary utility. The left one uses the plain form, which always worked. The right one adds a breakpoint segment — the form that used to match no pattern and silently emit nothing. Resize the window and the right-hand bars should step.

Viewport is currently xs — under 576px sm — 576px and up md — 768px and up lg — 992px and up xl — 1200px and up xxl — 1400px and up

1 · The reported bug

w-md-[40%] generated no CSS at all. The bar below is 100% wide until 768px, then 40% — if it never changes, the fix has regressed.

w-[65%]

w-[100%] w-md-[40%] — the fixed case

w-md-[40%]

2 · Every breakpoint resolves

One bar per breakpoint. Each should reach full width only once its own media query is active, so widening the window fills them top to bottom.

4 · The other half of the fix — it now complains

A class using bracket syntax that matches no family used to emit nothing and say nothing. It now warns at build time. The two classes below are deliberately bogus, so this page's own build prints a warning naming them — that warning is the test.

Run the build and read the output:

node bin/strata.js --build

Expect: 2 class(es) with arbitrary values matched no utility and emitted nothing: nope-[12px], lh-[1.15]

two deliberately unresolvable classes

Rebuild before viewing — this page's classes only exist in the output once the scanner has seen them: 

node bin/strata.js --build
