Each section tests one fixed issue. All boxes should render as described.

Bug 1 — rounded-pill on buttons FIXED

All four buttons below must have pill (fully rounded) corners — previously the btn border-radius silently won.

btn-primary rounded-pill btn-secondary rounded-pill btn-outline-primary rounded-pill btn-outline-danger rounded-pill
badge-pill (was always correct) btn-sm rounded-pill btn-lg rounded-pill

Bug 2 — Spacing arbitrary underscore → space FIXED

Shorthand values like p-[10px_20px] must produce padding: 10px 20px (not literal underscores).

p-[10px_30px] — 10px top/bottom, 30px left/right
m-[4px_12px_4px_24px] — 4-sided margin shorthand
px-[2rem] works as before
pt-[24px]

Bug 3 — fs-[...] for token-based font-size FIXED

text-[var(...)] was broken for tokens (routed to color). New fs-[...] prefix always means font-size.

fs-[var(--my-font-size)] → 1.3rem
fs-[2rem] fs-[0.75rem] fs-[clamp(1rem,2vw,1.5rem)]
text-[...] still works for bare literals and colors: text-[1.25rem] → font-size text-[#e63946] → color

Bug 4 — bg-[...] supports gradients FIXED

Previously hardcoded to background-color which rejects gradients. Now uses background shorthand.

bg-[linear-gradient(to_right,#6366f1,#ec4899)]
bg-[radial-gradient(circle,#fbbf24,#ef4444)]
bg-[#22c55e] — solid color still works

New — gap-[...] arbitrary value ADDED

Token-based gap values are now expressible — gap-[var(--my-gap)], gap-[1rem_2rem].

Item A
Item B
Item C

gap-[var(--my-gap)] = 1.5rem between items above

Row gap 8px
Col gap 32px
Item C

gap-[8px_32px] — row 8px, column 32px

New — fw-[...] arbitrary font-weight ADDED

Token-based or custom font-weight values — fw-[var(--my-weight)], fw-[350].

fw-[var(--my-weight)] = 700 fw-[350] thin-ish fw-[900] black fw-[100] hairline
