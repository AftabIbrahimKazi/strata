text-[] Arbitrary Value Routing

Values with a CSS length unit route to font-size. Everything else routes to color.

Should set font-size
text-[12px] This text should be 12px — smaller than base
text-[15px] This text should be 15px
text-[24px] This text should be 24px — larger than base
text-[1.25rem] This text should be 1.25rem
text-[2rem] This text should be 2rem — clearly larger
text-[0.75em] This text should be 0.75em — smaller than parent
Should set color
text-[#e63946] This text should be red (#e63946)
text-[#2a9d8f] This text should be teal (#2a9d8f)
text-[#f4a261] This text should be orange (#f4a261)
text-[rgb(99,102,241)] This text should be indigo (rgb)
text-[cornflowerblue] This text should be cornflowerblue (named)
Combined — size + color together
text-[20px] + text-[#e63946] 20px and red — both should apply
text-[1.5rem] + text-[#2a9d8f] 1.5rem and teal — both should apply
