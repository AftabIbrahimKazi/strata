@strata-packages/offcanvas

Standalone usage — no Strata CSS required

Right drawer

Right Drawer

Slides in from the right. Press Esc or click the backdrop to close.

Left drawer

Left Drawer

Slides in from the left using data-st-side="left".

Top drawer

Top Drawer

Slides in from the top using data-st-side="top".

Bottom drawer

Bottom Drawer

Slides in from the bottom using data-st-side="bottom".

Starts open by default

Developer sets aria-hidden="false" — drawer is open on page load, no JS needed.

Open by Default

This was open on page load — aria-hidden="false" set by the developer in HTML.

Static backdrop

Clicking the backdrop does nothing — only Escape or the close button dismisses.

Static Backdrop

Clicking outside does nothing. Use the Close button or press Esc.

API reference

// Open by CSS selector
StrataOffcanvas.open('#myDrawer')

// Open by element reference
StrataOffcanvas.open(document.querySelector('#myDrawer'))

// Close the current open drawer
StrataOffcanvas.close()

// Events fired on document
document.addEventListener('st:offcanvas:open',  e => { /* e.detail.offcanvas */ })
document.addEventListener('st:offcanvas:close', e => { /* e.detail.offcanvas */ })

HTML attributes

<!-- data-st-side  : set by developer, JS never changes it -->
<!-- aria-hidden   : set by developer for initial state, JS only updates the value -->

<div class="offcanvas" data-st-side="right"  aria-hidden="true">   <!-- starts closed -->
<div class="offcanvas" data-st-side="left"   aria-hidden="true">   <!-- starts closed -->
<div class="offcanvas" data-st-side="top"    aria-hidden="true">   <!-- starts closed -->
<div class="offcanvas" data-st-side="bottom" aria-hidden="false">  <!-- starts open   -->

<!-- Trigger -->
<button data-st-toggle="offcanvas" data-st-target="#myDrawer">Open</button>

<!-- Dismiss -->
<button data-st-dismiss="offcanvas">Close</button>

<!-- Static backdrop -->
<div class="offcanvas" data-st-side="right" data-st-backdrop="static" aria-hidden="true">
