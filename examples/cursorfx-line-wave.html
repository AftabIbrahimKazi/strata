Lines that ripple when you cross them

Move the pointer across any line below. A ripple starts where you crossed, travels along the line, and settles flat.

The preset injects the line itself — the page writes one attribute. No SVG to author, no script of your own.

1 — Replacing the original

The effect this preset replaces was a React component that rewrote an SVG path's d attribute every frame via GSAP. These are its exact defaults — amplitude 5px, 1.75 cycles, 1.4 travel, 1.1s, opacity 0.1→0.6, 2.5px glow — reproduced with no per-frame JavaScript at all.

Vertical dividers between grid cells — the original's use case. Orientation is detected from the box, so nothing has to be declared.

2 — What the package adds live

Every control below writes a CSS custom property. Nothing here re-renders geometry — the shape is a mask being scaled and slid.

Colour — any CSS paint

The line is a background behind a mask, not a stroke. So every gradient type works with no code in the preset: linear, radial and conic all just paint. 

data-st-cfx-line-wave-color=
  "conic-gradient(#f0f, #0ff, #f0f)"

A flat colour still goes through the engine's parser, so an unusable value warns instead of painting nothing.

density only applies to the two multi-stroke shapes: strokes per period for bars, rung count for helix. The single-stroke shapes ignore it.

What a shape costs

One period of geometry, generated once at mount and handed to CSS as a mask. Adding a shape is a path generator of a few lines — no new file, no new animation, nothing per frame. 

data-st-cfx-line-wave-shape="helix"
data-st-cfx-line-wave-density="6"

An unknown name warns, lists the real ones, and falls back to sine — a blank mask would look identical to a working line that happens to be invisible.

4 — The ripple starts where you crossed

Cross this line near the left, then near the right. The wave begins at the crossing point. The component this replaces always started at one end — it used the cursor only to decide which label glowed, never the wave itself. This is the part that needs a cursor package to exist. 

origin: 'pointer'   // default — start where the cursor crossed
origin: 'start'     // the reference's behaviour
origin: 'center'

5 — Retuning from a stylesheet

The preset writes an inline custom property only where an option differs from its default. Anything left alone is supplied by CSS, so a theme can retune the effect without touching markup or JavaScript.

↑ same preset, restyled by one class

.themed {
  --st-cfx-wave-color: linear-gradient(90deg, #ff2d55, #7df9ff);
  --st-cfx-wave-amplitude: 9px;
}

[data-st-theme="dark"] { --st-cfx-wave-peak-opacity: 0.8; }

6 — What it costs to run

Zero per-frame JavaScript

This preset has no render hook. The engine's frame loop does nothing for it. On hover it flips one attribute and writes at most one custom property; CSS does the rest.

It joins Magnetic and HoverFlicker as a preset with no per-frame cost — and it emits no particles, so it competes for no budget and composes freely with any canvas preset.

How the shape moves without redrawing

One period of a sine is a mask, tiled along the line.

  • cycles → mask-size
  • travel → animate mask-position-x
  • envelope → scaleY(), where scaleY(0) is the flat resting state
  • colour → a background, so gradients are free
