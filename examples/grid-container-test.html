Test 8 — Gutters (g-* · gx-* · gy-*)

Gutters control the spacing between columns. They are applied via CSS variables on the row, so they work without any JavaScript. g-0 removes all gutters. gx-* controls horizontal only. gy-* controls vertical only (visible when columns wrap).
