Getting Started

Add two files to your HTML and you are ready. Strata is JIT — only classes you actually use are included in the output CSS.

FilePurpose
strata.output.cssGenerated stylesheet — only used classes
strata.components.jsInteractive components (Modal, Skeleton)
strata.config.jsContent glob paths + input/output config
npm run buildProduction build — minified JS, readable CSS
npm run devWatch mode — rebuilds on file change
npm run minifySmallest output — minifies CSS + JS

Minimal HTML template

<!DOCTYPE html>
<html data-st-theme="light" lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My App</title>
  <link rel="stylesheet" href="dist/strata.output.css">
</head>
<body>

  <!-- your content using Strata classes -->

  <script src="dist/strata.components.js"></script>
</body>
</html>

Theming

Set data-st-theme on any element. Themes cascade — set it on <html> for the whole page or on a specific element for scoped theming. System preference is respected automatically when no attribute is set.

Skeleton Loader

Strata's native shimmer system. Three approaches — CSS-only for static shimmer, JS API for programmatic control, and auto-reveal for page-load transitions. All three use the same data-st-skeleton attribute and the same CSS.

Attribute / APIDescription
data-st-skeleton="true"Element shimmers — CSS ::before overlay covers content
data-st-skeleton="false"Element revealed — shimmer removed, content visible
data-st-skeleton="null"JS-managed parent — no parent overlay, children shimmer individually
Strata.skeleton.init(sel?)Register parent(s) for JS management — smart-detects leaf children
Strata.skeleton.show(sel?)Re-show skeleton on registered elements
Strata.skeleton.reveal(sel?, opts?)Reveal content — supports stagger and onReveal callback
Strata.skeleton.toggle(sel?)Toggle between skeleton and revealed
Strata.skeleton.isSkeleton(el)Returns true if element is currently in skeleton state

Set data-st-skeleton="true" directly on the card. The CSS ::before overlay covers all children automatically.
