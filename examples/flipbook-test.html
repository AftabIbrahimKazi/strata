Strata Flipbook
CSS-driven • drag to flip • organic animation
v1.1.0 · MIT

What it is

A JIT-friendly flipbook that renders HTML or PDF content as a page-flip book. All animation runs via CSS custom properties and data-st-* attributes — zero inline styles.

MITNo inline stylesStrata-compatibleStandalone

Swiper-like API

Wrap your pages and call one line.

StrataFlipbook('#book')

// or with options
StrataFlipbook('#book', {
  preset: 'magazine',
  pagination: 'dots',
  drag: true,
})

Drag to flip

Grab the bottom corner of any page and drag. On narrow screens (single-page mode) a horizontal swipe anywhere on the book triggers the flip.

Sound engine

Built-in synthetic page-rustle — no audio file needed. Override with your own:

  • sound.enabled: true
  • sound.src: '/my-turn.mp3'
  • sound.volume: 0.6
  • sound.mute: false

Pagination modes

Choose one or combine:

pagination: 'controls' // default
pagination: 'dots'
pagination: 'input'
pagination: 'thumbnails'
pagination: ['controls', 'dots']
pagination: 'none'

PDF source

Load any PDF via pdfjs-dist. Pages render to canvas and display as spreads. Export back to PDF with pdf-lib — all peer deps, all MIT / Apache-2.

pdfjs-distpdf-libhtml2canvas

Real 3D page turn

The page is a 3D leaf hinged at the spine — it lifts and twists from the grabbed corner, with shading and an edge sheen. Closed books show the cover alone with page thickness, and open and close with the same mirrored animation.
