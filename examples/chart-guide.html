1

Setup — Load the dependencies

Strata Chart renders via WebGL using Three.js. You need to load Three.js and OrbitControls before strata.components.js. That's it — no bundler or npm install required.

<!-- 1. Strata CSS -->
<link rel="stylesheet" href="strata.output.css">

<!-- 2. Three.js + OrbitControls via CDN -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/controls/OrbitControls.js"></script>

<!-- 3. Strata components (chart plugin is bundled here) -->
<script src="strata.components.js"></script>

<!-- Required CSS for the chart plugin -->
<style>
  .strata-chart        { position: relative; overflow: hidden; }
  .strata-chart-canvas { display: block; width: 100% !important; height: 100% !important; }

  .strata-chart-tooltip {
    position: absolute; pointer-events: none; opacity: 0;
    transition: opacity 150ms ease;
    /* style it however you like */
  }
  [data-st-chart-tooltip="true"] { opacity: 1; }
</style>
OrbitControls is optional. If you omit it the chart will still render and animate perfectly — users just won't be able to drag-rotate in 3D.
2

Your first chart

Call Strata.Chart.create(selector, options). Give it a container element and a data array — that's all that's required. The chart will fill 100% of the container's width and the height you set on it.

<!-- Give the container a height -->
<div id="myChart" style="height: 280px"></div>

const chart = Strata.Chart.create('#myChart', {
  type: 'bar',   // 'bar' | 'line' | 'pie' | 'scatter'
  data: [
    { label: 'Jan', value: 120, category: 'Jan' },
    { label: 'Feb', value: 180, category: 'Feb' },
    { label: 'Mar', value: 95,  category: 'Mar' },
    { label: 'Apr', value: 210, category: 'Apr' },
    { label: 'May', value: 160, category: 'May' },
  ],
})

// chart is now live — drag to orbit, hover bars to inspect
↑ Live chart. Drag to orbit in 3D. Hover a bar to see the tooltip.
3

Chart types

Set type to one of four values. Each renders differently but shares the same camera, interaction, and transition system.

bar
line
pie
scatter
// Bar  — categories aggregated, 3D boxes extruded
Strata.Chart.create('#el', { type: 'bar',     data: [...] })

// Line — points connected by polyline, no aggregation
Strata.Chart.create('#el', { type: 'line',    data: [...] })

// Pie  — arc slices, categories aggregated
Strata.Chart.create('#el', { type: 'pie',     data: [...] })

// Scatter — spheres sized by value, no aggregation
Strata.Chart.create('#el', { type: 'scatter', data: [...] })
Category aggregation: bar and pie charts group data by the category field and sum values. Line and scatter plot each point individually.
4

2D ↔ 3D views

Every chart supports seamless animated transitions between a cinematic 3D angle and a near-orthographic 2D view. A single PerspectiveCamera is used throughout — FOV, position, mesh depth, and group rotation all lerp together over 600ms.

const chart = Strata.Chart.create('#el', {
  type: 'bar',
  view: '3d',   // '2d' | '3d' — default '3d'
  data: [...],
})

// Flip the current view with a smooth transition
chart.toggleView()

// Go to a specific view
chart.setView('2d')
chart.setView('3d')

// Listen for when the transition finishes
Strata.Chart.create('#el', {
  data: [...],
  onChange: function(view) {
    console.log('Now in', view) // '2d' or '3d'
  },
})
Pie charts rotate on the X axis so the 2D view shows the flat circular face directly — no perspective distortion. All other chart types animate mesh depth (scale.z).
5

Hover & click interactions

A raycaster runs every animation frame. Hovering any data point emits an emissive glow and positions a tooltip. Clicking fires the onClick callback and the st:chart:click document event. Both work in 2D and 3D.

const chart = Strata.Chart.create('#el', {
  type: 'bar',
  data: [...],

  // Fires when user clicks a hovered bar/point/slice
  onClick: function(point) {
    console.log(point.label)    // 'Jan'
    console.log(point.value)    // 120
    console.log(point.category) // 'Revenue'
    console.log(point.index)    // position in data array
  },
})

// Or listen globally on document
document.addEventListener('st:chart:click', function(e) {
  console.log(e.detail) // same { label, value, category, index }
})

6

Data format

The data option accepts an array of plain objects. Only value is required — everything else is optional.

const data = [
  // Minimal — only value is required
  { value: 42 },

  // Common — label shows in tooltip, category drives aggregation
  { label: 'January', value: 120, category: 'Revenue' },

  // Full — timestamp and meta pass through to callbacks unchanged
  {
    label:     'March',
    value:     198,
    category:  'Revenue',
    timestamp: '2024-03-01',
    meta:      { region: 'APAC', forecast: 210 },
  },

  // null / undefined → treated as 0, no error thrown
  { label: 'May', value: null, category: 'Revenue' },
]

// Bar + pie aggregate by category — two rows with the same category
// are summed into one bar/slice
const barData = [
  { label: 'Mon', value: 50,  category: 'Week 1' },
  { label: 'Tue', value: 80,  category: 'Week 1' }, // → summed into 'Week 1' bar
  { label: 'Wed', value: 120, category: 'Week 2' },
]
Security: all string values are HTML-stripped before use. Labels are capped at 256 chars, categories at 128 chars. Max 100,000 data points.
7

Grid view, axis labels & scale

Four opt-in flags add reference lines and text labels directly into the Three.js scene using billboard sprites — visible and readable in both 2D and 3D. All default to false so they never impact performance when unused.

Toggle flags live

Strata.Chart.create('#el', {
  type: 'bar',
  data: [...],

  gridView:       true,  // horizontal scale lines + vertical column lines
  showAxisLabels: true,  // category name sprites below each data point
  showScale:      true,  // numeric Y-axis ticks on the left (0 → max)
  showGridLabels: true,  // numeric values at the right end of each grid line
                          // ↑ requires gridView: true
})
All four flags work on bar, line, and scatter charts. They are not applicable to pie charts.
8

Interactive grid highlighting

When highlightGridOnInteract is enabled, hovering a data point turns its column grid line and the nearest horizontal scale line blue. They restore the moment the cursor leaves. Requires gridView: true.

Strata.Chart.create('#el', {
  type: 'bar',
  data: [...],

  // Both flags are needed
  gridView:                true,
  highlightGridOnInteract: true,

  // Optional: add scale labels so you can read
  // the highlighted Y value
  showScale:               true,
})

// Works on line and scatter too
Strata.Chart.create('#el', {
  type: 'scatter',
  data: [...],
  gridView:                true,
  highlightGridOnInteract: true,
})
↑ Hover any bar to see the column and scale lines light up in blue. The highlight updates every animation frame — no extra code needed.
9

Dynamic data entries

Add, remove, or patch individual data points after the chart is created — without recreating it. Every method validates through the same pipeline, updates the geometry in place, and fires st:chart:update. The scale, grid, and labels all adjust automatically.

const chart = Strata.Chart.create('#el', {
  type: 'bar',
  data: [
    { label: 'Jan', value: 120, category: 'Jan' },
    { label: 'Feb', value: 180, category: 'Feb' },
  ],
})

// Add one point
chart.addDataPoint({ label: 'Mar', value: 95, category: 'Mar' })

// Add multiple at once
chart.addDataPoints([
  { label: 'Apr', value: 210, category: 'Apr' },
  { label: 'May', value: 160, category: 'May' },
])

// Remove by index (into the original data array)
chart.removeDataPoint(0)           // remove first
chart.removeDataPoints([1, 3])     // remove multiple

// Patch one field without touching the rest
chart.updateDataPoint(0, { value: 999 })
chart.updateDataPoint(1, { label: 'Renamed', value: 55 })

Colors & themes

Pass a colors array of any hex or CSS color strings. The plugin cycles through it if you have more data points than colors. When omitted it reads --st-primary, --st-secondary, --st-success, --st-warning, --st-info from the active Strata theme.

The theme option sets the scene background — 'auto' reads data-st-theme from <html> at creation time.

Default (Strata vars)

Warm palette

Cool palette

// Default — auto-reads Strata CSS vars
Strata.Chart.create('#el', { data: [...] })

// Custom palette — cycles if more points than colors
Strata.Chart.create('#el', {
  data: [...],
  colors: ['#ff6b6b', '#ffa07a', '#ffd700', '#ff8c00', '#dc143c'],
})

// Theme: 'auto' | 'light' | 'dark'
Strata.Chart.create('#el', { data: [...], theme: 'dark' })

// To re-theme a live chart: destroy and re-create
chart.destroy()
chart = Strata.Chart.create('#el', { ..., theme: 'auto' })

Options

All options passed to Strata.Chart.create(selector, options).

OptionTypeDefaultDescription
dataRawPoint[]requiredArray of data objects. See Step 6 for the full data format.
type'bar'|'line'|'pie'|'scatter''bar'Chart geometry. Bar and pie aggregate by category; line and scatter do not.
view'2d'|'3d''3d'Initial view. The camera starts here with no transition animation.
colorsstring[]Strata CSS varsHex/rgb color strings. Cycles if more data points than colors.
theme'auto'|'light'|'dark''auto'Scene background. 'auto' reads data-st-theme from <html> at creation time.
camera3d{x?,y?,z?,fov?}—Override any field of the 3D camera. Default: {x:3.5, y:6.5, z:9.5, fov:42}.
camera2d{x?,y?,z?,fov?}—Override any field of the 2D camera. Default: {x:0, y:2, z:22, fov:18}.
onReady(chart)=>void—Called once immediately after the first render.
onChange(view)=>void—Called after each 2D/3D transition completes. Receives the new view string.
onClick(point)=>void—Called when a hovered mesh is clicked. Receives {label, value, category, index}.
Feature flags — all default false, opt-in only
gridViewbooleanfalseXY-plane horizontal scale lines and vertical column lines. Bar, line, scatter.
showAxisLabelsbooleanfalseBillboard sprites below each point showing the X-axis category name.
showScalebooleanfalseNumeric Y-axis tick labels on the left at five scale steps (0 → max).
showGridLabelsbooleanfalseNumeric value at the right end of each horizontal grid line. Requires gridView: true.
highlightGridOnInteractbooleanfalseHighlight column + nearest horizontal grid line on hover. Requires gridView: true.

Methods

MethodDescription
chart.toggleView()Flip between 2D and 3D with the full animated transition.
chart.setView('2d'|'3d')Go to a specific view. No-op if already there.
chart.update(newData)Replace the full dataset. Preserves view, camera, and interaction state.
chart.addDataPoint(point)Append one raw data point. Fires st:chart:update.
chart.addDataPoints(points[])Append multiple raw data points in one rebuild.
chart.removeDataPoint(index)Remove one point by index in the raw data array.
chart.removeDataPoints(indices[])Remove multiple points in one rebuild.
chart.updateDataPoint(index, partial)Patch any fields of one raw data point.
chart.destroy()Remove canvas, free all Three.js memory, disconnect ResizeObserver, clear registry.
Strata.Chart.destroyAll()Call destroy() on every mounted chart on the page.
