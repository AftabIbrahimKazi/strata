Skeleton Loader

Built into Strata core — zero plugins, zero extra markup, fully theme-aware.

How it works: A ::before overlay physically covers all child content with an opaque shimmer. Text, buttons and images are all hidden underneath — no CSS specificity fighting needed. Add data-st-skeleton="true" to any parent element and everything inside shimmers. Switch themes above to see skeleton colours update automatically.

How It Works

One attribute · one line of JS · zero extra markup

<!-- One attribute on the parent — everything inside shimmers -->
<div class="card" data-st-skeleton="true">
  <div class="card-img-wrap"><img src="photo.jpg"></div>
  <div class="card-body">
    <h3 class="card-title">Article Title</h3>
    <p class="card-text">Description text</p>
    <button class="btn btn-primary">Read more</button>
  </div>
</div>

<script>
  // Show skeleton — one line
  card.setAttribute('data-st-skeleton', 'true')

  // Fetch data
  const data = await fetch('/api/article/1')

  // Reveal content — one line
  card.setAttribute('data-st-skeleton', 'false')
</script>

The skeleton uses a ::before pseudo-element overlay that sits on top of ALL child content via z-index: 9999. Text colour, button backgrounds, images — nothing shows through. No !important needed anywhere.

6. Buttons & Anchor Tags

Inline and inline-flex elements — handled automatically

Buttons and anchors are inline or inline-flex by default which causes overflow: hidden and ::before overlays to misbehave. Strata automatically forces them to inline-block when skeleton is active so the shimmer covers them correctly with proper border radius.

7. Border Radius Control

--st-skeleton-radius — independent from --st-border-radius

--st-skeleton-radius controls the corner rounding of ALL shimmer bars independently from the framework's global --st-border-radius. Default is 4px — subtle rounding like YouTube. For avatars and circular elements, border-radius: 50% from the element's own styles is inherited automatically by the shimmer.

Default — 4px
Sharp — 0px
Rounded — 8px
Pill — 999px
Circle avatar — border-radius 50% inherited
Rounded card image
/* Change globally */
:root { --st-skeleton-radius: 8px; }

/* Change per theme */
[data-st-theme="dark"] { --st-skeleton-radius: 2px; }

/* Change for one specific element */
<div style="--st-skeleton-radius: 999px;" data-st-skeleton="true">

/* Circle — inherits border-radius: 50% from element's own styles */
<div style="border-radius: 50%;" data-st-skeleton="true">

8. Body Level — Full Page Skeleton

Set on body or html — opt out nav and footer

<body data-st-skeleton="true">

  <!-- Nav is always visible — opt it out -->
  <nav data-st-skeleton="false">
    <a href="/">Brand</a>
    <a href="/about">About</a>
  </nav>

  <!-- Main content area shimmers while API data loads -->
  <main>
    <div class="card">...</div>
    <div class="card">...</div>
  </main>

  <!-- Footer is always visible — opt it out -->
  <footer data-st-skeleton="false">
    <p>© 2026 Acme Corp</p>
  </footer>

</body>

<script>
  // When all data is ready — one line reveals everything
  document.body.setAttribute('data-st-skeleton', 'false')
</script>

9. Customise the Skeleton

Override CSS variables — scoped globally, per-theme, or per-element

/* Change shimmer colours globally */
:root {
  --st-skeleton-base:     #ddd6fe;   /* purple tint */
  --st-skeleton-shine:    #ede9fe;
  --st-skeleton-duration: 1s;        /* faster shimmer */
  --st-skeleton-radius:   8px;       /* more rounded corners */
}

/* Dark mode override */
[data-st-theme="dark"] {
  --st-skeleton-base:  #1e1b4b;
  --st-skeleton-shine: #312e81;
}

/* Override for a specific section only */
.financial-dashboard {
  --st-skeleton-base:   #dcfce7;   /* green tint */
  --st-skeleton-shine:  #f0fdf4;
  --st-skeleton-radius: 999px;     /* pill shaped bars */
}
